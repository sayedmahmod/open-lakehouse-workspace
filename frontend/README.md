# open-lakehouse workspace frontend

The frontend is part of the repository-level open-lakehouse workspace. Read the
[root README](../README.md) for architecture, setup, configuration, capabilities,
roadmap, and development checks.

## Frontend commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The standalone dev server runs on `http://localhost:3000`. The root
`start.sh` launcher runs the complete API and frontend workspace on
`http://localhost:3002`.
